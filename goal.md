# Reglas de ejecución

## Testing real end-to-end

Debes probar absolutamente todo usando el navegador de forma real, simulando usuarios reales.

No asumas que algo funciona solo porque compila o porque existe código.

Cada flujo debe ejecutarse realmente.

Debes:

* Navegar por toda la aplicación
* Hacer clic en todos los botones
* Validar formularios
* Probar inputs inválidos
* Validar respuestas visuales
* Confirmar persistencia de datos
* Verificar errores
* Simular fallos
* Validar respuestas del backend
* Confirmar sincronización entre frontend y backend
* Revisar comportamiento en tiempo real
